# Cell-type neighbourhood enrichment

> Counts how often cells of two labelled types are adjacent in a spatial neighbour graph and compares each count with a label-shuffling null, returning a type-by-type enrichment matrix; the published standard is a permutation z-score, kept as the comparator, and singlet proposes a fitted directional model alongside it.

## 1. Question

For two cell types a and b on a fixed spatial graph, are there more or fewer directed edges from a-cells to b-cells than a label-shuffled null predicts? The inputs are one categorical label per cell or spot, a directed neighbour graph (stored, or built from coordinates) and an optional library key. The outputs are K by K enrichment matrices with counts and, where computed, p-values. A correct answer states the null it uses, and a positive value means the graph holds more a-to-b edges than that null allows, not that the two types interact.

## 2. Why this task matters and where the field stands

Neighbourhood enrichment is the first summary of tissue architecture in spatial transcriptomics: it shows which types touch, which avoid each other, and which pairs deserve interaction or niche analysis [R1]. Its status is **contested**. Implementations in different frameworks use different nulls and graphs, so the same labels can give different signs and magnitudes [R1, R3, R4]. A 2025 bioRxiv comparison of neighbour-preference methods has its Figure 4 data generated by the NEP_SpaSim scripts [R2, R6]. The open problems are:

- The null is not settled. Shuffling labels on a fixed graph, re-pairing endpoints and shuffling within domains answer different questions, and no comparison of them on real tissue is cited here [R1, R4].
- Direction is not settled. Directed graphs such as k-nearest neighbours are often asymmetric, so the a-to-b and b-to-a values differ, and their interpretation is not agreed.
- Multiplicity is not controlled by default. The squidpy output gives z-scores for K² correlated pairs without p-values or false-discovery control, and the Giotto default adjustment is none [R1, R4].
- Label source matters. Labels from clustering on the same graph make enrichment positive by construction, and spot labels from deconvolution blur adjacency.
- Spatial autocorrelation is not varied in the directional designs. The NEP_SpaSim scripts vary infiltration and cluster size only [R6], so their results do not show how the label-shuffle null behaves where types form contiguous domains.

## 3. Theory and insight

| Symbol | Meaning |
|---|---|
| $N$, $K$ | cells (or spots) and label levels |
| $\ell_i$ | label of cell $i$; $L\in\{0,1\}^{N\times K}$ is its one-hot matrix |
| $A$, $M$ | directed adjacency and its number of stored non-self entries (weights ignored) |
| $n_a$ | number of cells with label $a$ |
| $P$, $S$ | permutations (squidpy, rapids-singlecell) or simulations (Giotto) |
| $M_u$, $m_a$ | unique undirected edges, and endpoints of type $a$ among them |

**Directed count.** The observed statistic is the number of stored a-to-b entries. It is exact for CSR input after duplicates are summed and zeros removed.

$$O_{ab}=\sum_i\sum_{j\in\mathcal N(i)}\mathbf 1[\ell_i=a]\,\mathbf 1[\ell_j=b]=(L^{\top}AL)_{ab}\tag{1}$$

**Null mean.** Under uniform relabelling without replacement on a fixed graph without self-edges, $P(\ell_i=a,\ell_j=b)=n_a(n_b-\delta_{ab})/\{N(N-1)\}$ for $i\neq j$, so

$$\mathbb E_\pi[O_{ab}]=\frac{M\,n_a(n_b-\delta_{ab})}{N(N-1)}\tag{2}$$

For a directed 6-nearest-neighbour graph $M=6N$, so the mean is about $6n_an_b/N$. Pairs with small $n_an_b$ have small expected counts, where the normal reference is not guaranteed.

**Permutation z-score.** Squidpy and rapids-singlecell estimate the mean and SD from $P$ shuffles of the labels and report

$$z_{ab}=\frac{O_{ab}-\bar O^{\pi}_{ab}}{\hat\sigma^{\pi}_{ab}},\qquad \hat\sigma^{\pi}_{ab}=\Big\{\tfrac1P\textstyle\sum_{p=1}^{P}\big(O^{(p)}_{ab}-\bar O^{\pi}_{ab}\big)^2\Big\}^{1/2}\tag{3}$$

The SD uses divisor $P$. It is zero for constant columns, where squidpy returns NaN. The result is a standardised deviation, not a p-value. Under normality the Monte Carlo error of the SD at $P=1000$ is about 2 percent, and $|z|\ge2$ corresponds to a two-sided probability of about 0.046.

**Total normalisation.** Squidpy's `total` divides each row by $n_a$. Because $n_a$ is fixed under relabelling, $z$ is unchanged and only the raw scale moves.

**Conditional ratio.** Let $C_{ab}=\sum_i\mathbf 1[\ell_i=a]\,\mathbf 1\big[\sum_{j\in\mathcal N(i)}\mathbf 1[\ell_j=b]\ge1\big]$ count the a-cells with at least one b-neighbour, and set $R_{ab}=O_{ab}/C_{ab}$, with $C_{ab}=0$ replaced by 1. The denominator depends on the labels, so there is no closed-form null. Squidpy computes $z$ on $R$ under the same shuffle, and the stored `conditional_ratio` is $C_{ab}/n_a$.

**Endpoint null.** Giotto uses the unique undirected edges of a Delaunay network and counts $U_{ab}$ edges of each unordered type pair. Shuffling the pooled endpoint types and splitting them into two halves is a uniform random matching of the $2M_u$ endpoints, so

$$\mathbb E[U_{ab}]=\frac{m_a m_b}{2M_u-1}\ (a\neq b),\qquad \mathbb E[U_{aa}]=\frac{m_a(m_a-1)}{2(2M_u-1)}\tag{4}$$

This is exact under the matching [R4]. The null preserves each type's endpoint count, so it is degree-weighted and hub cells contribute more than in the cell-count null of (2). Giotto then reports the fold change $e_{ab}=\log_2\{(U_{ab}+1)/(\bar U^{\rm sim}_{ab}+1)\}$ and empirical one-sided p-values, $p^+_{ab}=\#\{s:U^{(s)}_{ab}\ge U_{ab}\}/S$ and $p^-_{ab}=\#\{s:U^{(s)}_{ab}\le U_{ab}\}/S$. Ties count toward both sides, so $p$ can be exactly 0. The PI score is $\mathrm{PI}_{ab}=-\log_{10}\{\min(\tilde p^+_{ab},\tilde p^-_{ab})+1/S\}\,e_{ab}$, where the tilde denotes multiplicity adjustment. PI is a ranking score, not a likelihood.

**Model-based proposal.** Singlet's candidate models each cell's type given counts of its neighbours' types, $X_{ib}=\sum_{j\in\mathcal N(i)}\mathbf 1[\ell_j=b]$:

$$P(\ell_i=a\mid\ell_{-i})=\frac{\exp\big(\alpha_a+\sum_b\beta_{ab}X_{ib}\big)}{\sum_{a'}\exp\big(\alpha_{a'}+\sum_b\beta_{a'b}X_{ib}\big)}\tag{5}$$

$\beta_{ab}$ is the change in the log-odds of type $a$ per additional $b$-neighbour, holding the other neighbour counts fixed, and $\beta_{ab}\neq\beta_{ba}$ in general. Abundance enters only through the intercepts $\alpha$, so $\beta$ is not mechanically scaled by $n_an_b$. The model is fitted by maximum pseudolikelihood, the product of these conditionals. Besag's 1974 paper [R9] gives the conditional specification of such lattice models. The labels are observed, so no latent variables are needed. The pseudolikelihood approximates the joint pairwise Markov field. Consistency needs weak dependence among cells, and intervals need a spatial-block bootstrap or a sandwich variance.

**Estimands.** Each output and each ground-truth quantity is defined as follows.

- `zscore` (none): the observed a-to-b count minus its shuffle mean, divided by the shuffle SD.
- `count`: the raw number of stored a-to-b entries, which scales with $n_an_b$.
- `conditional_ratio`: $C_{ab}/n_a$, the fraction of a-cells with at least one b-neighbour.
- Conditional `zscore`: the standardised $R_{ab}$, the mean number of b-neighbours among a-cells that touch b.
- `log2_enrichment`: the log2 ratio of unordered edge counts to the endpoint-null mean, with pseudocount 1.
- `p_high`, `p_low`, `p_adj`: empirical one-sided p-values, with the chosen multiplicity adjustment applied to `p_adj`.
- `PI`: a heuristic ranking of adjusted significance times fold change, not a probability.
- $\beta_{ab}$: the conditional log-odds change in type $a$ per additional $b$-neighbour.
- Planted truth (B1, B2): 1 for each directed pair the design plants and 0 otherwise, so the truth is a binary indicator per directed pair.
- Negative-control truth (B3): the empty set, so every flag is false.

**Regime and assumptions.** The shuffle tests assume a fixed graph and labels that are exchangeable given the graph. Four failures recur. Spatial autocorrelation makes contiguous domains look enriched in their own neighbours, because a global shuffle ignores that tissue types are contiguous [R8]. Degree heterogeneity and tissue boundaries make the cell-count and endpoint nulls differ. Graph choice changes the statistic itself: directed k-nearest-neighbour entries and undirected Delaunay edges give different counts and can flip signs. Small clusters make the SD unstable, and pooled slides without a library key are treated as one tissue. The endpoint method assumes Delaunay edges represent real contacts. The model assumes the pseudolikelihood is adequate and that cells are weakly dependent given the graph.

**Why the heuristic works, and what a model adds.** The permutation z is a nonparametric standardisation, exact in its mean and cheap to compute. It does not give calibrated direction, joint inference over $K^2$ pairs, a reusable parameter, or uncertainty that accounts for dependence between neighbouring cells. The model gives $\beta$ with intervals, can be compared across samples, and can feed downstream tasks, but only simulation can show that its intervals are calibrated.

**Insight.** The null choice matters more than the z formula. Relabelling keeps the graph and cell counts, while endpoint re-pairing keeps the degree-weighted endpoint composition. Normalisations change the estimand, not only the scale: `conditional` moves the question from edge count to presence-conditioned edge count. The data alone cannot decide between these, so benchmarks must plant both direction and presence and must include spatially structured negative controls.

## 4. Methods landscape

| Method | Paradigm | Core idea | Reference |

| Conditional ratio z-score (squidpy `normalization='conditional'`) | heuristic | Divides counts by the number of a-cells touching b, then z-scores the ratio under the same shuffle | [R1] |

## 5. Proposed singlet approach

**Routes.** The label-permutation and conditional statistics are ported from squidpy, the endpoint null and PI score from Giotto, and the GPU batching from rapids-singlecell (routes per source in section 12). The raw count is a trivial port. Equation (5) is new and is implemented from its equations, not from any published code.

**Proposed defaults.** `label_permutation_zscore` on the stored graph, with 1000 permutations and seed 0. No cluster is dropped by default, but every result reports cluster sizes beside its z-scores so that small clusters stay visible. `knn6` is used only when no graph is stored, and the Delaunay network is symmetrised for the permutation methods.

**Model-based option.** Equation (5) is fitted by pseudolikelihood with Newton steps, with intervals from a spatial-block bootstrap and a sandwich variance as a cross-check. It is not a default and is not in the enum. It would enter only once its code exists and it meets the falsification tests below. It is rejected if, on B2 at $p=0$, more than 10 percent of unplanted directed pairs have 95 percent intervals excluding zero; if, on B1 at infiltration of at least 0.3, the intervals for the two directional $\beta$ overlap in more than half of the 20 seeds; or if its B1 directional recovery is more than 0.05 below the squidpy baseline. These thresholds are proposed.

**ML stack.** The model is small and evaluated on every call, so it is hard-coded in CUDA with cuSPARSE and cuBLAS. $X=AL$ is one sparse-dense product of cost $O(MK)$, the $K^2$ coefficients are fitted by Newton steps with small dense solves, and permutation counts are batched sparse products, as in rapids-singlecell. PyTorch is used only if neural neighbourhood models are added later.

**Kernels and backends.** The CPU path evaluates permutations in parallel and accumulates the sums of $d$ and $d^2$ in 64-bit integers, which keeps the SD exact up to one rounding. The GPU path batches at most 128 permutations with batch times cells at most $2^{23}$, and adds the zero-SD guard that the rapids-singlecell port lacks. The graph is held in memory and is not streamed.

## 8. Benchmarks

Every accuracy benchmark applies each comparator at its section 4 defaults, with 1000 permutations and seed 0, unless it states otherwise. The graph is the directed 6-nearest-neighbour graph for the squidpy and rapids-singlecell statistics and the undirected Delaunay network for Giotto. Each design is replicated with 20 seeds, and results are reported per design and per level, not only pooled. Ties count as failures. For unordered pairs the score is the larger of the two directed z-values, or the PI score for Giotto. Directional metrics are undefined for Giotto, which tests unordered edges. Software versions and seeds go into the provenance record.

### B1. Directional preference in the NEP_SpaSim designs (published design)

- **Goal**: Recover a planted directed neighbour preference between two types across infiltration levels, and separate its direction from the reverse.
- **Ground truth**: Planted simulation. For each design the truth is the directed pair (infiltrating type I, cluster type G) at infiltration above 0, with cell types taken from the simulator output. The truth set is empty at infiltration 0.
- **Datasets**

| Dataset | Source | Modality, species, size | License | Notes |
|---|---|---|---|---|
| NEP_SpaSim designs 1 to 3, simulated 2D point patterns | NEP_SpaSim scripts [R6]; spaSim simulator [R7] | simulated; background of 5000 cells; `set.seed(610)` | see section 12 | Data are not shipped and must be regenerated. Design 1: one 500-cell cluster infiltrated at 0.1 to 0.7. Designs 2 and 3: two clusters, with infiltration 0 to 0.7 of one type. The cluster that is not infiltrated changes size from 510 to 440 across levels. |

- **Metrics**

| Metric | Definition (ties, thresholds, aggregation) | Direction | Role | Reference |
|---|---|---|---|---|
| directional_recovery | Fraction of designed directed pairs with $z_{GI}>0$ and $z_{GI}>z_{IG}$, where $z_{GI}$ is the z of cluster cells having infiltrating-type neighbours; ties fail; averaged over 20 seeds | maximise | primary | — |
| planted_pair_AUROC | Mann–Whitney AUROC of unordered-pair scores, planted pairs positive, average ranks for ties, pooled per level | maximise | primary | — |
| false_positive_rate | Fraction of unplanted unordered pairs with score at least 2 (for Giotto, adjusted p at most 0.05 and fold change above 0) | minimise | guardrail | — |
| infiltration_monotonicity | Spearman correlation between infiltration proportion and $z_{GI}$ across replicates | maximise | guardrail | — |

- **Comparators**: squidpy label-permutation z; squidpy conditional z; Giotto endpoint method; rapids-singlecell label-permutation z, to check GPU agreement; squidpy raw counts, for ranking only.
- **Protocol**: Regenerate the designs with 20 replicate seeds, 610 to 629, in place of the single script seed. Apply each comparator to each replicate.
- **Acceptance criterion**: Proposed, not from the literature. For the label-permutation z at infiltration of at least 0.3, directional_recovery and planted_pair_AUROC are each at least 0.90 over 20 seeds, and false_positive_rate is at most 0.10 across all designs.
- **Known pitfalls**: The simulator defines the truth, so a null that matches its uniform placement is advantaged. Design 1 has constant cluster size and should be reported separately, because in designs 2 and 3 size and preference are confounded.

### B2. Planted directed-preference generator (proposed)

- **Goal**: Measure detection power and null calibration as N, K and preference strength vary, with the planted set known by construction.
- **Ground truth**: Planted simulation. The planted set is the disjoint directed pairs (1 to 2), (3 to 4) and so on, giving $\lfloor K/2\rfloor$ pairs per tissue. A planted pair $a\to b$ means that a's neighbourhood is enriched in b.
- **Datasets**

| Dataset | Source | Modality, species, size | License | Notes |
|---|---|---|---|---|
| Generated tissues (recipe below) | singlet (new) | simulated 2D points; N in $\{5\times10^3, 5\times10^4\}$; K in $\{4,8,16\}$; p in $\{0,0.2,0.4,0.6\}$; 20 seeds per cell of the grid | — | No external data. |

- **Recipe**: (1) Place $N$ cells uniformly in the unit square, with $K$ labels of equal proportion. (2) Set $r$ to the median distance to the sixth nearest neighbour in the untreated tissue. (3) For each planted pair $(a,b)$, delete each $b$-cell with no $a$-cell within $r$ with probability $p$. (4) Density-matched control: at $p=0.4$ and $N=5\times10^4$, delete the same expected number of $b$-cells uniformly at random. This control has an empty truth set.
- **Metrics**

| Metric | Definition (ties, thresholds, aggregation) | Direction | Role | Reference |
|---|---|---|---|---|
| directional_recovery | As in B1, over the planted pairs | maximise | primary | — |
| planted_pair_AUROC | As in B1 | maximise | primary | — |
| null_calibration | Fraction of unplanted directed pairs with $\lvert z\rvert\ge2$ at $p=0$, pooled over seeds; the normal reference is 0.046 | toward 0.046 | guardrail | — |

- **Comparators**: As in B1. Directional recovery is undefined for Giotto.
- **Protocol**: Apply each comparator to the 20 seeds at each $(N,K,p)$ on the directed 6-nearest-neighbour graph (Giotto on Delaunay), with 1000 permutations and seed 0. Report the calibration curve at $p=0$ and the density-matched control separately.
- **Acceptance criterion**: Proposed. At $p=0$, null_calibration is at most 0.10 for the label-permutation z; at $N=5\times10^4$ and $p\ge0.4$, directional_recovery is at least 0.90.
- **Known pitfalls**: Surviving $b$-cells lie near $a$-cells, so the reverse direction is also enriched, and directional_recovery counts a win for the planted direction rather than a zero reverse z. Deletion also changes local density, which the density-matched control separates from neighbour preference.

### B3. Domain-structured negative control (proposed)

- **Goal**: Quantify how much the global shuffle inflates flags when types form contiguous domains with no pairwise preference beyond domain membership [R8].
- **Ground truth**: Consistency (negative control). By construction no directed pair has preference beyond domain membership, so the true set is empty. The flag rate is the fraction of the $K(K-1)$ off-diagonal directed pairs with $z\ge2$. Flags on geometrically adjacent domains count as false, because the design contains no preference between them.
- **Datasets**

| Dataset | Source | Modality, species, size | License | Notes |
|---|---|---|---|---|
| Generated domains (recipe below) | singlet (new) | simulated 2D points; N = $5\times10^4$; K in $\{4,8\}$; correlation length $\ell$ in $\{5,20\}$ cell diameters | — | No external data; 20 seeds per $(K,\ell)$. |

- **Recipe**: (1) Place $N$ cells uniformly in the unit square. (2) Draw a Gaussian random field with squared-exponential covariance and correlation length $\ell$, with the cell diameter taken as the median nearest-neighbour distance, approximated with random Fourier features. (3) Assign labels by quantile bins of the field into $K$ domains. (4) Partition the square into a 4 by 4 grid of equal tiles; the tile index is the library key for the within-tile null.
- **Metrics**

| Metric | Definition (ties, thresholds, aggregation) | Direction | Role | Reference |
|---|---|---|---|---|
| fpr_global | Fraction of off-diagonal directed pairs with $z\ge2$ under the global shuffle | minimise | primary | — |
| fpr_block | The same fraction under the within-tile shuffle (library key = tile) | minimise | primary | — |
| inflation_ratio | fpr_global divided by fpr_block; 1 means no inflation; undefined when fpr_block is 0, in which case both rates are reported | toward 1 | guardrail | — |

- **Comparators**: squidpy label-permutation z, global; squidpy label-permutation z, within tile; Giotto endpoint method, flagged by adjusted p at most 0.05 and fold change above 0 (global only).
- **Protocol**: Apply all comparators to each $(K,\ell)$ with 20 seeds, 1000 permutations and seed 0. Report the rates per $(K,\ell)$ together with the tile count.
- **Acceptance criterion**: Proposed. fpr_global is at most 0.10. If it is exceeded, the excess is reported as a known limitation; no literature threshold applies.
- **Known pitfalls**: Within-tile shuffling removes differences in composition between tiles, and with 16 tiles its estimate is unstable, so the tile count is reported with every result. A global shuffle flags boundary-adjacent domains even without preference, so the reported rate is boundary-inclusive.

### B4. Sensitivity to graph, label noise and abundance (proposed)

- **Goal**: Measure how stable the z-matrix and planted recovery are under graph, label-noise and abundance changes on the B1 tissues.
- **Ground truth**: Consistency. The planted pairs are those of B1 and are unchanged by the perturbations. The reference is the unperturbed analysis, and the normalisation is that of B1.
- **Datasets**

| Dataset | Source | Modality, species, size | License | Notes |
|---|---|---|---|---|
| B1 tissues with perturbations: directed 6-NN versus Delaunay graph; label noise, where each label is replaced by a uniform random type with probability 0.1; thinning of one planted type to 50 percent | singlet (derived) | as B1 | — | Perturbations are applied one at a time. |

- **Metrics**

| Metric | Definition (ties, thresholds, aggregation) | Direction | Role | Reference |
|---|---|---|---|---|
| rank_stability | Spearman correlation of off-diagonal z values between perturbed and reference analyses | maximise | primary | — |
| planted_recovery_under_perturbation | directional_recovery (B1) under each perturbation | maximise | primary | — |
| sign_flip_rate | Fraction of directed pairs whose z sign differs between the directed 6-NN and Delaunay graphs | minimise | guardrail | — |

- **Comparators**: squidpy label-permutation z and conditional z. Giotto is excluded because rank stability and sign flips need directed scores.
- **Protocol**: Use the B1 designs at infiltration 0.3 and 0.7, with 20 seeds, and apply one perturbation at a time. Report each perturbation separately.
- **Acceptance criterion**: Proposed. The drop in directional_recovery under label noise at 0.1 is at most 0.10, and sign_flip_rate between the directed 6-NN and Delaunay graphs is at most 0.10.
- **Known pitfalls**: Changing the graph changes the estimand, since directed entries and undirected edges are different quantities, so graph differences are reported as effects, not noise. Thinning changes $n_a$ and therefore the count scale, so only rank stability is used to judge it.

### P1. Performance and scaling

Wall time and peak memory for the label-permutation z with $P=1000$ on directed 6-nearest-neighbour graphs at $N=10^4$, $10^5$ and $10^6$ cells and $K=10$ or $30$, on CPU with one thread and with all threads, and on GPU. The conditional method and rapids-singlecell are the comparators. Cost is $O(PM)$ time and $O(N+K^2)$ memory per worker. Hold fixed: $P$, the graph (built outside the timed region), $K$, the seed, the thread count and the hardware, and record the CPU and GPU models and memory. The scales are proposals, and thresholds are set after a baseline measurement.

## 10. Risks, pitfalls and open questions

- **Evidence gaps.** The Schiller et al. comparison is cited as its 2025 bioRxiv preprint; its methods, datasets and numeric results are not described here, so the metrics in B1 are singlet's own and make no claim to match it. The journal version was not located. The COZI method's own code is not cited, so the conditional statistic is specified from squidpy's implementation, whose docstring names COZI as the source of its denominator. Besag (1975), usually cited for the pseudolikelihood estimator, was not checked.
- **Data risks.** B1 data are regenerated by the NEP_SpaSim scripts, which call spaSim 1.4.0 (version as stated in the NEP_SpaSim README); the spaSim code was not reviewed. No real tissue with ground-truth labels is used.
- **Implementation differences.** The rapids-singlecell port drops cells with missing labels and has no zero-SD guard, whereas squidpy raises an error and returns NaN, and squidpy changed its shuffling in 1.4.0 [R3], so results from earlier versions are not directly comparable. Line references are pinned to squidpy f030690, Giotto b4a774f, rapids-singlecell e110792 and NEP_SpaSim 4a2419c. The rapids-singlecell documentation disagrees about whether this function exists, but the code defines it.
- **Dropped benchmark.** An expert-annotated adjacency benchmark on the squidpy Visium H&E mouse-brain dataset (`visium_hne_adata`) is not published here, because its must-touch and must-not-touch pairs are undefined. Domain experts should freeze such lists before any method is applied.
- **Performance evidence.** No published timing for this statistic is cited, so the P1 scales are proposals and the thresholds remain open.
- **First experiment.** Apply the squidpy label-permutation z and the endpoint method to the B3 domain control at K = 4 and $\ell$ = 20 over 20 seeds. The result tests the largest suspected inflation and decides whether the within-tile null should be a default option or only a diagnostic.
