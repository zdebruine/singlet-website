Same study, two ways: CELLxGENE vs. singlet.bio

We took public GEO studies that are in both CZ CELLxGENE Discover and singlet.bio, downloaded each from both, and timed it on the same connection. Measured 23 September 2026 in a Chrome browser on a ≈90 Mb/s link. Each number is the median of 2–3 runs, with the cache disabled.

70GEO studies in both resources (223 GSE accessions are linked from 393 CELLxGENE collections)
16×fewer bytes for GSE185224: 107 MB vs 1,754 MB
1.3 sto fetch one sample's count matrix from a study file (two HTTP Range requests)

Read these numbers fairly. The two files are not the same content. CELLxGENE H5ADs carry normalized and raw matrices, embeddings and curated metadata. singlet files carry raw counts for every barcode plus read-derived layers. Cell counts differ because each resource calls cells differently and may hold different samples. Both downloads were limited by the client's connection. The Census API path (cellxgene_census.get_anndata) was not timed here; the script below measures it.
